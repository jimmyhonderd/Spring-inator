# Spring-inator

Pixel-platformspel met een VJ-held, in "Vroeger was alles beter"-stijl met een LEDJOCKEY-tintje.

**Speel / installeer:** https://jimmyhonderd.github.io/Spring-inator/

## Installeren op Android

1. Open de link hierboven in Chrome.
2. Tik op ⋮ (rechtsboven) → **App installeren**.
3. De app staat daarna tussen je apps, start schermvullend en werkt offline.

## Besturing

- Touch: linkerhelft van het scherm vasthouden = naar links, rechterhelft = naar rechts; kort tikken of omhoog vegen = springen (langer vasthouden = hoger). Geen knoppen.
- Pc: pijltjes, spatie = springen, P = pauze.

## Wat erin zit

- 5 levels met platforms, ?-blokken, munten, vijanden in de VWAB-kleuren (plat te springen) en een VWAB-bord als finish.
- Elke 20 munten een extra leven; score, levens en highscore op het toestel.
- Parallax-skyline met VWAB-billboards; staand en liggend.
